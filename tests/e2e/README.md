# 组日历 E2E 测试用例

## 测试用例说明

本目录包含组日历功能的 E2E 测试用例，使用 Playwright 进行自动化测试。

### 测试用例覆盖范围

1. **用户切换功能**：测试组日历中的用户切换下拉菜单是否正常工作
2. **欢迎语更新功能**：测试切换用户后，右上角的欢迎语是否更新为当前选择用户的用户名
3. **任务展示功能**：测试组日历是否显示所有用户的任务
4. **权限控制功能**：测试用户只能操作自己的任务，操作他人任务时是否显示权限不足提示

## 测试脚本使用方法

### 安装依赖

```bash
# 安装 Playwright
npx playwright install

# 安装项目依赖
npm install
```

### 运行测试

```bash
# 启动开发服务器
npm run dev

# 在另一个终端运行测试
npx playwright test tests/e2e/group-calendar.spec.ts
```

### 查看测试报告

```bash
npx playwright show-report
```

## 测试环境要求

- Node.js 18+ 
- 开发服务器运行在 http://localhost:5175
- 后端服务器运行在 http://localhost:3001

## 测试数据准备

为了进行完整的测试，需要准备以下测试数据：

1. **用户数据**：至少两个用户账号
2. **组数据**：一个测试组，包含至少两个成员
3. **任务数据**：每个用户至少有一个任务
4. **打卡数据**：部分任务有打卡记录

## 测试注意事项

1. 测试前确保开发服务器和后端服务器都已启动
2. 测试过程中不要手动操作浏览器
3. 测试完成后，测试数据会自动清理

## 测试用例维护

- 当组日历功能发生变化时，需要更新相应的测试用例
- 定期运行测试，确保功能正常
- 新增功能时，需要添加相应的测试用例
